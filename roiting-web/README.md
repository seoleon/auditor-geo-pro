# Roiting · Mockups de la web B2B (entregable 1)

Prototipos navegables HTML/CSS para elegir la dirección visual antes de construir la web en Elementor. **No se ha tocado WordPress.**

| Archivo | Contenido |
|---|---|
| `index.html` | Índice: investigación (fase 1), sistema de diseño (fase 2), comparativa, vista móvil en vivo y validación |
| `propuesta-a/index.html` | Propuesta A «Editorial técnico» (clara, naranja señal, serif editorial) |
| `propuesta-b/index.html` | Propuesta B «Revenue OS» (oscura, lima, estética de producto SaaS) |
| `capturas/` | Capturas de página completa en 1440 px (1x) y 390 px (2x), más el primer pantallazo de cada una |

Para abrirlo, haga doble clic en `roiting-web/index.html` en Chrome. Las fuentes se cargan desde Google Fonts, así que hace falta conexión.

## Notas importantes
- Las cifras de los dashboards son **datos de ejemplo** y así se indica en cada maqueta.
- Las cifras de casos (tk accelis Plastics Ibérica, Simufy) proceden de roiting.com según resultados de búsqueda y llevan la marca **«pendiente de verificación»**.
- Logotipo y colores son provisionales hasta recibir el manual de marca.
- Cada página es un único archivo, con el CSS de los tokens en `:root`, para trasladarlo después a variables y clases globales de Elementor Atomic V4.
