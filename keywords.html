Cómo conectar la Google Ads API (gratis)
  1. Crea un proyecto en Google Cloud y activa la Google Ads API.
  2. Crea un cliente OAuth de tipo Aplicación de escritorio y copia el ID y el secreto.
  3. En tu cuenta de administrador (MCC) de Google Ads, abre el Centro de API y solicita un developer token. El acceso Basic permite 15.000 operaciones al día.
  4. Copia .env.example a .env, rellena los datos y ejecuta npm run keywords:auth para obtener el refresh token.
  5. Opcional: añade ANTHROPIC_API_KEY para clasificar con IA. Arranca con npm start.
